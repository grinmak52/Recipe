# Recipe

Учебный веб-проект на Django для создания и просмотра рецептов.

Пользователь может зарегистрироваться, войти в систему, просматривать рецепты, а также создавать, редактировать и удалять собственные рецепты.

## Возможности

- регистрация пользователя;
- вход и выход из аккаунта;
- просмотр списка рецептов;
- пагинация списка рецептов;
- просмотр отдельного рецепта;
- создание рецепта авторизованным пользователем;
- загрузка изображения рецепта;
- автоматическое создание уникального `slug`;
- редактирование только собственных рецептов;
- удаление только собственных рецептов;
- категории рецептов;
- сообщения об успешном создании, изменении и удалении рецепта.

## Модели

### Category

- `name` — название категории;
- `slug` — уникальный slug категории.

### Recipe

- `name` — название рецепта;
- `slug` — уникальный slug рецепта;
- `description` — описание;
- `ingredients` — ингредиенты;
- `step` — шаги приготовления;
- `image` — изображение;
- `created` — дата создания;
- `updated` — дата последнего изменения;
- `user` — автор рецепта;
- `category` — категория рецепта.

Один пользователь может иметь несколько рецептов, и одна категория может содержать несколько рецептов.

## Запуск проекта

### 1. Клонировать или скачать проект

Перейти в корневую директорию проекта.

### 2. Создать виртуальное окружение

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установить зависимости

```bash
pip install -r requirements.txt
```

### 4. Применить миграции

Перейти в каталог с `manage.py`:

```bash
cd django_app
python manage.py migrate
```

### 5. Запустить сервер разработки

```bash
python manage.py runserver
```

После запуска проект будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

## Основные URL

| URL | Назначение |
|---|---|
| `/` | Список рецептов |
| `/create/` | Создание рецепта |
| `/accounts/login/` | Вход |
| `/accounts/register/` | Регистрация |
| `/accounts/logout/` | Выход |
| `/<slug>/` | Просмотр рецепта |
| `/<slug>/update/` | Редактирование своего рецепта |
| `/<slug>/delete/` | Удаление своего рецепта |
| `/admin/` | Административная панель Django |

## Особенности реализации

Для создания и редактирования рецептов используется `ModelForm`.

Для страниц списка, просмотра, создания, редактирования и удаления используются class-based views (`ListView`, `DetailView`, `CreateView`, `UpdateView`, `DeleteView`).

Доступ к созданию рецептов ограничен для авторизованных пользователей через `LoginRequiredMixin`.

Редактирование и удаление дополнительно защищены `UserPassesTestMixin`: изменять рецепт может только его автор.

Для получения автора и категории вместе с рецептом в `DetailView` используется `select_related()`.

Генерация уникального slug вынесена в отдельный сервис `recipe/service.py`.

## Административная панель

Через `/admin/` можно управлять пользователями, категориями и рецептами.

Для доступа необходимо создать суперпользователя:

```bash
python manage.py createsuperuser
```

## Проверка проекта

Перед завершением разработки полезно выполнить:

```bash

python manage.py makemigrations --check
python manage.py test
```
